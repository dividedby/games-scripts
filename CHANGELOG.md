# Changelog

All notable changes to the userscripts in **games-scripts** are documented here.
Each script keeps its own history in a `CHANGELOG.md` in its folder:
[Connections Palette](connections/CHANGELOG.md), [Minute Cryptic Plus](minute-cryptic/CHANGELOG.md),
[NYT Games Dark](nyt-dark/CHANGELOG.md) and [Wordle Shortlist](wordle/CHANGELOG.md).
This file records only changes that apply to every script.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/2.0.0/),
and versions follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).
